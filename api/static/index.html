Co mówi ostatni sprawdzian?

Na ostatniej sprawdzonej dacie model przegrał z prostym założeniem niezmienionej ceny. Historyczna poprawa nie potwierdza stabilnej przewagi w przyszłości.

Jak czytać tę prognozę?

Kwartał odniesienia: początek prezentowanej ścieżki. Jego cena jest estymacją (nowcastem), ponieważ publikacje cen mają opóźnienie.

Zmiana procentowa: odnosi każdą cenę do ostatniej znanej ceny wejściowej. Nie jest stopą zwrotu w jednym kwartale ani obietnicą zysku.

MAPE: średni bezwzględny błąd procentowy. Niższa wartość oznacza lepszą prognozę. Pokazany sprawdzian dotyczy całego panelu, a nie tylko wybranego miasta. Historia była wcześniej analizowana; nie jest to niezależny test prospektywny.

Zakres: 17 miast, rynek pierwotny i wtórny. Model nie przewiduje czasu sprzedaży i nie daje rekomendacji kupna lub sprzedaży.
